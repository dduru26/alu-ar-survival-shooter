# AR Survival Shooter — Custom AR Plane Tracking Combat Experience

A mobile **augmented-reality survival shooter** built with **Unity 6 (6000.4) and AR Foundation 6.4**.
Scan the floor, place the arena on a detected plane, then survive the timer while **Melee** and **Shooter** enemies spawn on the real-world surface and hunt you down.

**Author:** Duru Donald Onyebuchi — ALU, AR/VR Development with Unity I
**Platform:** iOS (ARKit) — tested on iPhone. Android (ARCore) is also configured.

---

## Features

| Requirement | Implementation |
|---|---|
| AR plane detection & anchored gameplay | `ARPlaneManager` (horizontal only) + `ARPlacementController` raycasts the tap and anchors the arena with `ARAnchorManager.AttachAnchor` |
| Custom plane tracker with my name | `NamePlane` prefab — custom material tiling **"DURU DONALD ONYEBUCHI"** across every detected plane, cyan outline |
| Tap-to-place, single instance | Only the first valid tap spawns the arena; later taps are ignored. Plane detection then stops and planes hide (`PlaneVisibilityController`) |
| Two enemy types | `MeleeEnemy` (2 HP, 0.5 m range, 1.2 s cooldown) and `ShooterEnemy` (4 HP, stops at 1.6 m, fires from 2.6 m) |
| Object pooling for shooting | Generic `ComponentPool<T>`; 30 player + 40 enemy bullets created up front, recycled forever — no `Instantiate`/`Destroy` during play |
| Game states | State pattern: **Menu → Placement → Playing → GameOver** |
| Local leaderboard | `LeaderboardService` — latest **5** sessions, saved with PlayerPrefs (JSON), persists between launches |
| Complete UI | Start menu, placement hint, HUD (health, score, time, kills), game-over summary, leaderboard |
| Sound | `AudioManager` + `SoundLibrary`: player shoot, player death, enemy spawn, enemy shoot, melee attack (+ hit, kill, victory, UI, ambience) |
| Difficulty (bonus) | `Easy` / `Hard` ScriptableObjects (round length, HP, spawn rate, max enemies, shooter ratio, speed, damage) |

## How to play
1. **START** (pick Easy or Hard first).
2. Move the phone slowly until your name appears on the floor, then **tap the floor** to place the arena.
3. **Hold anywhere** to shoot at the crosshair. Brutes rush you; drones keep their distance and shoot — move to dodge.
4. Survive until the timer hits 0. Your result is saved to the **Leaderboard**.

## Architecture (Assets/_Project/Scripts)

```
Core/      GameManager (Singleton) · GameStateMachine + Menu/Placement/Playing/GameOver states (State)
           GameEvents (Observer hub) · GameSession · DifficultySettings (ScriptableObject)
AR/        ARPlacementController (tap-to-place + anchor) · PlaneVisibilityController
Player/    PlayerHealth (IDamageable) · PlayerShooter · DamageFlash · ShowWhilePlaying
Combat/    IDamageable, IPoolable, Team · ComponentPool<T> (Object Pool) · Projectile · ProjectilePool
Enemies/   Enemy (abstract) → MeleeEnemy, ShooterEnemy · EnemyFactory (Factory + pools) · EnemySpawner
UI/        UIPanel (abstract) → MainMenu/Placement/HUD/GameOver/Leaderboard panels · UIManager
Data/      LeaderboardService (PlayerPrefs JSON)
Audio/     AudioManager (Singleton, Observer) · SoundLibrary (ScriptableObject)
Editor/    Phase setup tools + BuildTools (one-click iOS / Android builds)
```

**OOP:** encapsulation (private serialized state, read-only properties), abstraction (`Enemy`, `UIPanel`, `IGameState`, `IDamageable`), inheritance (enemy and panel hierarchies), polymorphism (`Behave()`, `OnShow()`, state `Enter/Tick/Exit`).
**Patterns:** Object Pool, Singleton, State, Factory, Observer.
**Algorithm:** enemy spawn points are accepted only if they fall inside a detected plane's boundary (even–odd point-in-polygon test).

## Build & run (iOS)
1. Open the project in **Unity 6000.4.5f1** with iOS Build Support installed.
2. **Tools ▸ AR Survival ▸ Build iOS (Xcode project)** → exports to `Builds/iOS`.
3. Open `Builds/iOS/Unity-iPhone.xcodeproj` in Xcode, set your **Team** under *Signing & Capabilities*, choose the iPhone and **Run**.

Requires an ARKit-capable iPhone (A9 or newer) running iOS 15+.
For Editor testing, **XR Simulation** is enabled: press Play, hold the right mouse button and use WASD to scan, click the floor to place.
